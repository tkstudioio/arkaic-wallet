## Implementation notes for the executor

- Read each file in full before editing — do not assume class strings from memory
- For `components/ui/skeleton/index.tsx`: read the file first to identify the exact tokens used before applying the mapping
- Respect the `tva` compound variant structure: each `parentCompoundVariants` entry is an object with `variant`, `action`, and `class` keys — replace only the color portion inside `class`
