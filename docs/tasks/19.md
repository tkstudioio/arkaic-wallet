### Task 1.2 — Gluestack + Tailwind integration

#### CSS Variables (`components/ui/gluestack-ui-provider/config.ts`)

Added `--color-arkaic-*` variables in both light and dark themes using nativewind's `vars()` RGB space-separated format:

| Variable | RGB Value | Source |
|----------|-----------|--------|
| `--color-arkaic-background` | `15 23 42` | `#0F172A` |
| `--color-arkaic-foreground` | `248 250 252` | `#F8FAFC` |
| `--color-arkaic-muted` | `148 148 148` | `#949494` |
| `--color-arkaic-primary` | `136 39 138` | `#88278A` |
| `--color-arkaic-primary-foreground` | `226 226 226` | `#E2E2E2` |
| `--color-arkaic-fill` | `26 35 56` | `#1A2338` |
| `--color-arkaic-border` | `198 185 197` | `rgba(198,185,197,0.66)` |
| `--color-arkaic-shadow` | `116 59 116` | `rgba(116,59,116,0.33)` |
| `--color-arkaic-positive` | `85 170 88` | `#55AA58` |
| `--color-arkaic-negative` | `170 85 87` | `#AA5557` |
| `--color-arkaic-warning` | `226 164 111` | `#E2A46F` |

> `border` and `shadow` store only the RGB channels; alpha is applied in tailwind (`/0.66` and `/0.33`).

#### Tailwind Config (`tailwind.config.js`)

**Colors** — `colors.arkaic.*` mapped to CSS variables:

```
bg-arkaic-background, text-arkaic-foreground, bg-arkaic-primary,
text-arkaic-muted, border-arkaic-border, ...
```

**Spacing** — `spacing.arkaic-*`:

```
p-arkaic-md, m-arkaic-sm, gap-arkaic-lg, ...
```

**Border Radius** — `borderRadius.arkaic-*`:

```
rounded-arkaic-button, rounded-arkaic-card, rounded-arkaic-full
```

### Result

No existing components were modified. The app continues to work identically.
